# 🚌 Bus Ticketing System - EasyRide

A full-stack bus ticketing system with facial recognition, route search, wallet top-ups, and secure authentication. Built with React, Node.js, Express, MongoDB, and Python (Flask + face_recognition).

---

## 🚀 Getting Started

Follow the steps below to run the project locally.

---

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/smart-bus-ticketing.git](https://github.com/TiffanyYongNgikChee/EasyRide
cd EasyRide
```

### 2. Install Node Dependencies (Frontend & Backend)
```bash
Make sure you're in the project root (or navigate to the frontend/backend folders as needed):

npm install
```

### 3. Start the Node/Express Server
```bash
node server.js
```

### 4. Start the React Frontend
```bash
In another terminal:
npm start
This runs the React app on http://localhost:3000/.
```

### 5. Run the Python Face Recognition Server
```bash
Make sure Python 3 is installed. Create a virtual environment (optional but recommended):
cd python-app.py
pip install -r requirements.txt

Then run the Flask server:
python app.py
```
